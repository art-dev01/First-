# IRONFIELD

Браузерная танковая арена на HTML, CSS и JavaScript. Откройте `index.html` в браузере и нажмите **«В бой»**. Игра работает локально, без сервера, установки зависимостей и подключения к интернету.

## Управление

| Клавиши      | Действие                   |
| ------------ | -------------------------- |
| W / ↑        | Вперёд                     |
| S / ↓        | Назад                      |
| A, D / ←, →  | Поворот корпуса            |
| Мышь         | Прицеливание башней        |
| ЛКМ / Пробел | Стрельба; можно удерживать |
| Q / E        | Поворот башни с клавиатуры |
| P / Escape   | Пауза и продолжение        |
| R            | Новый бой                  |

На сенсорном экране доступны кнопки движения и огня. Без ручного прицеливания башня на сенсорных устройствах выбирает ближайшего видимого противника. Звук включается кнопкой в правом верхнем углу.

Боты объезжают укрытия и стреляют в ответ. Уничтожение всех противников запускает следующую волну. Зелёные ящики восстанавливают до 35 единиц брони, переход к следующей волне — до 20. При переключении вкладки бой автоматически ставится на паузу.

## Файлы

- `index.html` — игровой экран и интерфейс.
- `src/css/style1.css` — оформление и адаптивность.
- `src/js/engine.js` — движение, столкновения, снаряды, боты и волны.
- `src/js/game.js` — Canvas, эффекты, звук и обработчики управления.
- `tests/` — проверки симуляции и связи управления с игровым состоянием.

Проверки запускаются через встроенный тестовый модуль Node.js:

```sh
node --test tests/*.test.cjs
```

Это локальная игра с ботами, без сетевого мультиплеера. Числа в Canvas обозначают координаты игрового мира; размеры интерфейса в CSS заданы в `rem` с шагом `0.125rem`.
